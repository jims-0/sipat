# Sipat 🌱🔍

**Crop disease detection from a leaf photo, for Filipino smallholder farmers.**

*Sipat* is Tagalog for looking at something closely to inspect it, the way a
farmer or agriculturist studies a leaf. (Formerly "Tanim Guard".)

Take a photo of a leaf; Sipat says which disease it most likely has, shows
which part of the leaf the AI looked at, and gives treatment guidance in Tagalog
and English. If it is not confident, it says so and asks for a better photo.

## What it does

- **Leaf diagnosis** with a MobileNetV3-Small model trained on PlantVillage
  (transfer learning). 19 classes across **tomato, pepper (sili), potato and corn**,
  plus "not a leaf" and "unsupported plant".
- **Says "not sure"** instead of guessing when its confidence is below the
  threshold measured on the test set (0.7), and recognises photos with no leaf
  or leaves of plants it does not cover.
- **Heat map** (class activation map) showing where on the photo the evidence
  for the answer sits - computed from the model for each photo.
- **Treatment guidance** for every disease, in Tagalog and English: cause,
  signs, what to do now, prevention, spray options by active ingredient, organic
  options, when to bring a sample to the Municipal Agriculture Office, and the
  references to check against. No doses: "follow the FPA-registered label".
- **Adviser** ("Magtanong"): ask a follow-up question. Common questions (dose,
  spraying, harvesting, prevention...) are answered from the curated guidance
  word for word; others go to a small local model (Ollama, qwen2.5:3b) whose
  answer is rejected if it contains an amount, loops, or is empty.
- **Field test set.** On every result the farmer (or MAO) can confirm it or pick
  what it really was. Those labelled phone photos download as a zip from the
  Estadistika page, and `scripts/evaluate_field.py` measures the app on them.
- **Plots and follow-ups.** Tag each scan to a plot (taniman), set a "scan again
  in 3/7/14 days" reminder, and re-scan the same plant: the result shows before
  and after and whether it improved. History filters by plot, crop, result or text.
- **Aklatan (library).** Every disease with its guidance and a sample photo,
  readable without taking a picture.
- **Printout for the MAO.** One A4 page (TL or EN): photo, heat map, result,
  guidance, the farmer's notes and a box for the agricultural technologist.
- **Statistics:** scans per week, result types, feedback and field accuracy.
- **Runs on one PC, offline.** The model runs locally with LiteRT (TensorFlow
  Lite); photos never leave the computer. A phone on the same Wi-Fi can use it.

## Measured results

From `docs/EVALUATION.md` (generated by `scripts/evaluate.py` - re-run it after
retraining; do not edit numbers by hand):

| | |
|---|---|
| Test photos (never seen in training) | 4,454 |
| Accuracy | 95.0 % |
| Correct answer in the top 3 | 99.5 % |
| Macro F1 | 0.941 |
| Answered at the 0.7 threshold / accuracy on those | 93.7 % / 97.6 % |
| App model (TensorFlow Lite, float32) | 3.8 MB; same top answer as the trained model on 179/179 checked photos |

Weakest classes: Tomato Early Blight is often confused with Late Blight
(recall 0.77); some unsupported-plant leaves are called Potato Healthy
(precision 0.70); Corn Northern Leaf Blight vs Gray Leaf Spot.

**Limits.** These are PlantVillage lab photos (one leaf, plain background, even
light). Accuracy on photos taken in a field is expected to be lower and **has
not been measured yet** - the field test set workflow above is how to measure it
(see `TRAINING.md`, "Measuring on field photos"). There is **no rice** - PlantVillage has no rice photos.
No field trial with farmers has been done.

## Run it

**Easiest (Windows):** double-click `start.bat`. The first run creates a
private Python environment and installs the app packages (needs internet once);
then the browser opens. Python 3.10+ must be installed.

**By hand:**

    pip install -r requirements.txt
    python run.py

Open http://localhost:5000 (the console also prints the address for a phone on
the same Wi-Fi). Set `TANIM_DEBUG=1` only when developing alone - debug mode
exposes a code console to the network.

**Windows exe:** `powershell -ExecutionPolicy Bypass -File build_exe.ps1` builds
`dist\Sipat\Sipat.exe` and a zip to copy to any Windows PC (no Python
needed there).

**Adviser (optional):** install Ollama (https://ollama.com) and run
`ollama pull qwen2.5:3b-instruct`. Without it the written guidance still works.

## Train it yourself

See [TRAINING.md](TRAINING.md): download PlantVillage, `prepare_dataset.py`,
`train_model.py` (~30 min on a laptop CPU), `evaluate.py`, `export_tflite.py`.

```
├── app/
│   ├── __init__.py          app factory, per-install secret key, markdown filter

│   │                        printout, field-set export, stats
│   ├── models.py            SQLite (diagnoses, labels, plots, reminders)
│   ├── ml/
│   │   ├── classes.py       the 21 classes (PlantVillage folder names)
│   │   ├── inference.py     LiteRT model -> ok / unsure / not_leaf / other_plant
│   │   ├── gradcam.py       class activation heat map
│   │   ├── treatment_data.py  curated EN/TL guidance with sources
│   │   ├── treatment.py     formats the guidance
│   │   ├── adviser.py       retrieval-first adviser + guarded local model
│   │   └── model/           tanim_guard.tflite, labels, CAM weights, reports
│   ├── templates/  static/
├── scripts/                 prepare_dataset, train_model, evaluate, export_tflite,
│                            evaluate_field (phone photos), make_library_thumbs
├── docs/EVALUATION.md       generated test-set report + confusion matrix
│   (FIELD_EVALUATION.md   generated by evaluate_field.py once field photos exist)
├── tests/                   pytest suite
├── start.bat  run.py  desktop.py  build_exe.ps1  tanim_guard.spec
└── TRAINING.md
```

## Credits

- **Dataset:** PlantVillage - Hughes & Salathé (2015); "Plant leaf diseases
  dataset without augmentation", Mendeley Data, doi:10.17632/tywbtsjrjv.1.
- **Model:** MobileNetV3 (Howard et al. 2019), ImageNet weights via Keras.
- **Heat map:** Class Activation Mapping (Zhou et al. 2016), equivalent here to
  Grad-CAM (Selvaraju et al. 2017).
- **Guidance references:** UC IPM, Cornell Vegetable MD Online, Penn State
  Extension, CIP, CIMMYT. Not reviewed by the DA - confirm with your MAO.
